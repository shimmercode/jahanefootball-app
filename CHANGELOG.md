# Changelog

## 1.0.0 — 2026-08-15

### New features
- Flutter Android app with RTL Persian UI
- Home feed, news detail, search, football center, match detail
- WordPress plugin exposing `/wp-json/jahan-football/v1/*`
- Static production JSON API under `backend/public/v1`
- GitHub Actions for test, APK build and tagged releases

### Known issues
- Firebase credentials were not provided
- Dedicated WordPress production host was not provided
- Local sandbox cannot install Flutter/Android SDK (Google download hosts blocked)

### Minimum Android
6.0 (API 23)
